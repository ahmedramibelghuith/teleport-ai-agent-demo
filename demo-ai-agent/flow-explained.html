🔎 How the AI Agent Answers One Question

Think of it like a brilliant detective locked in a room — he can only write notes. A messenger carries his notes to a librarian who fetches facts from a giant filing cabinet.

Messenger ⇄ Librarian

Get ready. The Messenger wakes up the Librarian and asks, “What can you look up for me?” The Librarian replies, “I can run lookups in the filing cabinet.”

MCP handshake → list_tools → ["run_read_query"]
▼
1
You → Messenger → Brain

You ask your question. The Messenger hands the Brain your question plus a note: “Here are the lookups you’re allowed to request.”

"Checkout is slow — investigate" + tool list → Claude
▼
2
Brain → Messenger

The Brain writes a note — it can’t move. Instead of an answer it says: “I can’t reach the cabinet myself. Please run this lookup and tell me what you find.”

stopReason: "tool_use" → run_read_query(sql: "SELECT … GROUP BY payment_provider")
▼
3
Messenger → Librarian

The Messenger carries the request over to the Librarian. (The Messenger never opens the cabinet itself — it just delivers the note.)

call_tool("run_read_query", { sql }) over MCP
▼
4
Librarian → Filing Cabinet

The Librarian actually opens the cabinet and runs the lookup. This is the only one who touches the data — using the key (password) on file.

db.py → psycopg2 → RDS executes the SELECT 🔑
▼
5
Cabinet → Librarian → Messenger

The facts come back. The cabinet returns the rows to the Librarian, who hands them to the Messenger.

rows → [{ payment_provider: "legacy_gateway", avg_ms: 11962 }]
▼
6
Messenger → Brain

The Messenger gives the facts to the Brain. “Here’s the result of the lookup you asked for.”

toolResult → Claude (second Bedrock call)
▼
7
Brain → decides

The Brain reads the facts and decides: either “I need one more lookup” (go back to step 2) or “I’ve got it!” and writes the final diagnosis.

stopReason "tool_use" → loop · or "end_turn" → final answer
🔁 Steps 2 → 6 repeat until the Brain has enough. In your real run it looped 8 times before answering.

The 3 things to remember

  • 🧠 The Brain only thinks — it writes notes (“run this lookup”), it never touches the data.
  • 🏃 The Messenger is the hub — the only one talking to both the Brain and the Librarian, carrying notes back and forth in a loop.
  • 📚 The Librarian does the work — a separate program that actually opens the filing cabinet and runs the lookup.

👉 Where Teleport will go (next phase): on the arrows in steps 3–4 — the path to the Librarian and the cabinet. Instead of a key (password) kept on file, the agent will show a short-lived ID badge that expires on its own, and every lookup gets logged.
