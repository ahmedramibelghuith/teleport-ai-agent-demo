🗄️ Demo database setup

Setting up the world: seed.py & admin_setup.py

Two small scripts run once before the demo — one builds the data with a hidden bug, the other hands the agent a deliberately limited key.

1seed.py — build the world (with a hidden bug)

Fills the database with realistic order history… and plants the slow payment provider the agent will hunt down.

🔎 The agent will DISCOVER this slow provider on its own — that’s the whole demo.

2admin_setup.py — issue the agent its limited badge

Creates a brand-new database account for the agent — a “visitor badge”, not the master key.

🛡️ Least privilege — the agent gets exactly what it needs, and nothing it doesn’t.
